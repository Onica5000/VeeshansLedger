### A correction to a correction

The **Efreeti Great Staff** source was changed *twice*. An earlier pass read a note on the
Eye of Veeshan page saying the staff "also drops off Noble Dojorn", and the source was widened
on that basis. The audit disputed it, and a direct fetch of `Efreeti_Great_Staff` showed the
structured `dropsfrom` field lists **Eye of Veeshan only**. The item page won; the wiki
contradicts itself here, and the note on the Eye page is the weaker source.

Worth remembering: **a prose annotation on a boss page is not evidence against an item page's
structured field.**

## Code defects found and fixed

**1. Cross-character file pairing (correctness bug).**
`find_exports()` chose the achievements file and the inventory file *independently*, each by
newest timestamp. With two characters exporting to the same folder, it could pair one
character's achievements with another's inventory and silently report nonsense. Files are now
grouped by the `<Character>_<server>` stem, characters with both files are preferred, and a
picker appears in the title bar when more than one exists. Covered by
`test_never_cross_pairs_two_characters`.

**2. Manual overrides were unreachable.**
`save_overrides()` existed and was never called — the manual-override feature was in the model
but had no UI. Double-clicking a row in the Farming List now marks a component as already held,
persisted to `%APPDATA%\VeeshansLedger\overrides.json`, with a count and a Clear button on the
Setup tab.

## Known gaps — deliberately not fixed

| Gap | Why |
|---|---|
| **NO DROP / Attunable flag per component** | Would tell you whether a guildmate can hand you an item. Most boss components are NO DROP; Efreeti-cycle items are mostly Attunable. Captured as a zone note rather than per-item, because the per-item data is not consistently published |
| **Wind Rune Meda's class list** | Its wiki page literally says `Class: NONE`. The value in the dataset is derived from the Tests that use it and is flagged `rune_unverified` |
| **Deep-link URLs to item pages** | Several canonical page titles use a backtick rather than an apostrophe (`Spiritualist\`s Ring`, `Al\`Kabor's Cap`) and one is lowercase (`Spiroc Earth totem`). Links would need a title-normalisation map |
| ~~Sirran vs boss-drop key conflict~~ | **RESOLVED 2026-08-31 by player report: Sirran the Lunatic does not exist in EverQuest Legends.** Island bosses drop the keys directly. `Plane_of_Sky_Keys` is stale classic-EQ content. The token table has been removed from the app |
| **No app icon** | Cosmetic |

## Method note

Rendered eqlwiki HTML garbles some names — Island 4's boss appears variously as "King of
Storms", "King of Sky" and "King of Spades" when it is **Keeper of Souls**. Always query the
API for wikitext. This is recorded in `CLAUDE.md` so it is not rediscovered.
